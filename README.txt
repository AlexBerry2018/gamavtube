КРИСТАЛЛ-2000 — Android-приложение (APK)

Игра лежит внутри приложения (папка app/src/main/assets). Работает без браузера
и без интернета. Пиксельные шрифты скачиваются автоматически во время сборки
и встраиваются в APK — на телефоне они есть сразу. Сохранения хранятся в самом приложении.

СПОСОБ 1 — собрать в облаке GitHub (ничего ставить не нужно)
1. Зарегистрируйся на github.com → New repository → имя kristall-2000 → Create.
2. На странице репозитория нажми «uploading an existing file» и перетащи
   ВСЁ СОДЕРЖИМОЕ этой папки (включая скрытую папку .github!) → Commit changes.
   Если папка .github не видна: в Проводнике Вид → Показать → Скрытые элементы.
   Если GitHub её не загрузил: Add file → Create new file → в имени набери
   .github/workflows/build-apk.yml → вставь текст из этого файла → Commit changes.
3. Открой вкладку Actions — там запустится «Собрать APK» (5–8 минут).
   Если не запустилась сама: выбери её слева → Run workflow.
4. Когда появится зелёная галочка, открой запуск → внизу Artifacts →
   скачай Kristall2000-apk.zip → внутри app-release.apk.

СПОСОБ 2 — Android Studio
1. Установи Android Studio (developer.android.com/studio).
2. File → Open → выбери эту папку. Дождись окончания Gradle Sync (первый раз долго).
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: app/build/outputs/apk/debug/app-debug.apk

УСТАНОВКА НА ТЕЛЕФОН
Перекинь .apk на телефон (Telegram, кабель, Google Диск), открой его и разреши
установку из этого источника. Иконка «Кристалл-2000» появится среди приложений.
APK подписан тестовым ключом — подходит для своих тестов и для друзей, но не для
Google Play (для магазина нужен свой ключ, скажи — подготовлю).

ОБНОВЛЕНИЕ ИГРЫ
Замени app/src/main/assets/index.html новой версией и подними versionCode
в app/build.gradle на 1. Пересобери тем же способом и установи поверх —
сохранения останутся.
